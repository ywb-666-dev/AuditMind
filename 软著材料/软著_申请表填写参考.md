## 四、软件功能与技术特点

**【软件功能介绍 — 约 300 字，直接填入申请表】**

本系统基于 FastAPI 框架搭建后端服务，采用 Streamlit 框架实现前端流式交互可视化界面，是一套完整的智能化财务数据处理应用软件。系统通过前后端接口联动，实现财务数据接收、多维度运算处理、流式实时输出、可视化展示等核心功能。

后端提供完整的 RESTful API 接口服务，涵盖用户认证、舞弊检测分析、AI 智能问答、报告生成与导出、会员订阅管理等模块；前端通过 Streamlit 组件实现数据上传、参数配置、结果渲染、图表展示等交互操作。系统具备完整的业务逻辑与独立执行能力，可稳定部署于服务器环境运行。

**【技术特点 — 约 200 字】**

系统核心技术特点包括：（1）前后端分离架构，后端基于 FastAPI 提供高性能异步 API 服务，前端基于 Streamlit 实现流式实时交互；（2）双模融合检测算法，结合传统财务指标分析与生成式 AI 文本风险分析进行舞弊识别；（3）SSE 流式输出技术，AI 问答模块采用服务器推送事件实现回答内容的实时逐字输出；（4）SHAP 可解释性分析，基于博弈论方法对模型判断依据进行可视化解释。
